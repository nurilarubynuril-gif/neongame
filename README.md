

Мини-игра в стиле Geometry Dash, созданная на JavaScript с использованием HTML5 Canvas.


- Автоматическое движение персонажа
- Прыжки и гравитация
- Препятствия и система столкновений
- Подсчет прогресса
- Restart после Game Over
- Неоновый arcade стиль

## Technologies
- HTML5
- CSS3
- JavaScript
- Canvas API

## Run
Открой `index.html` в браузере.
